## 測試步驟

1. 經場域同意後連接兩台同型號攝影機，確認 Windows 可同時辨識。
2. 啟動應用程式，指定兩路實體裝置、MJPG、1080p/30，填入經確認可鎖定的手動參數。
3. 檢查實際影格尺寸與驅動回報格式／FPS，確認沒有設定警告。以實拍畫面確認曝光、白平衡及對焦不再自動變動。
4. 連續運作至少 30 分鐘；記錄開始／停止時間、報告檔名及異常。正常停止以取得 `final` 統計。
5. 使用相機／驅動具備的硬體序號或獨立量測工具取得真正丟幀率；目前 OpenCV 主機序號只能代表成功讀取數。
6. 以外部時碼或高幀率拍攝顯示器量測端對端延遲，比較測試初期與結束前。主機讀取耗時不能取代此量測。
7. 另開一輪中斷測試，拔除單路再接回，確認另一條取像工作持續、UI 保持回應、原來源恢復；與正式穩定性數據分開。
8. 依需要比較 YUY2、不同 USB Host Controller 及 Media Foundation 候選後端，記錄格式、頻寬及解碼成本。後端比較尚需額外實作或工具。
